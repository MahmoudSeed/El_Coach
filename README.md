# ⚡ أيرون كوتش (IronCoach Pro v2.2)
**منصة التدريب الرياضي والتغذية الأونلاين المتكاملة (PWA)**

منصة ويب تقدمية (Progressive Web App) مصممة بمعايير احترافية لمدربي اللياقة البدنية وكمال الأجسام (Online Coaching)، تجمع بين **لوحة تحكم إدارية شاملة للكوتش** و**تطبيق تفاعلي ذكي للمتدربين** يعمل بكفاءة على الهواتف الذكية والحواسيب مع دعم كامل للعمل بدون إنترنت (Offline-First) ونظام تصميم مزدوج (**النمط الداكن الفاخر Dark Mode** و**النمط الفاتح الرياضي Light Mode**).

---

## 🌟 أبرز المميزات (Key Features)

### 👑 أولاً: لوحة تحكم الكوتش (Coach Admin Panel)
- **إدارة كاملة للمشتركين (Full CRUD & Search)**: إضافة متدربين جدد مع حساب تلقائي للسعرات، تعديل بيانات وخطط المتدربين، حذف الحسابات، وبحث فوري بالاسم أو الهاتف أو حالة الاشتراك.
- **عداد اشتراكات ذكي (30-Day Subscription Engine)**: فحص تلقائي لصلاحية الاشتراك وتصنيف المشتركين إلى:
  - 🟢 **ساري (`active`)**: أكثر من 3 أيام متبقية.
  - 🟡 **ينتهي قريباً (`expiring`)**: 3 أيام أو أقل متبقية.
  - 🔴 **منتهي (`expired`)**: 0 يوم (يتم تحويل المتدرب تلقائياً لشاشة التجديد ورفع الإيصال).
- **معاينة حية لحساب المتدرب (Impersonation Mode)**: الدخول لحساب أي مشترك بضغطة زر لمعاينة جدوله الغذائي والتدريبي كما يراه تماماً.
- **مراسلة واتساب المباشرة**: زر مراسلة فوري لكل متدرب لإرسال تذكير التجديد أو متابعة الخطة.
- **إعدادات الدفع الهجين والهوية**: تخصيص اسم الكوتش، رقم الواتساب، السعر الشهري، العملة، وأرقام المحافظ (Vodafone Cash, InstaPay, STC Pay, IBAN, Stripe).
- **النسخ الاحتياطي والاستعادة (JSON Backup & Restore)**: تصدير واستيراد قاعدة بيانات المنصة بالكامل بملف JSON مشفر محلياً لحماية البيانات.

### 🏋️‍♂️ ثانياً: تطبيق المتدرب التفاعلي (Trainee Experience)
- **تبديل النمط (Dark / Light Theme)**: زر تبديل فوري بين الوضع الداكن الفاخر والوضع الفاتح عالي التباين مع حفظ التفضيل تلقائياً.
- **حاسبة السعرات والماكروز العلمية (NASM / Mifflin-St Jeor)**: حساب دقيق لمعدل الأيض الأساسي (`BMR`)، الاستهلاك اليومي (`TDEE`)، وتوزيع البروتين والكارب والدهون الصحية واحتياج الماء.
- **مكتبة الـ 100 وجبة ومولد الدايت الذكي**:
  - 100 وجبة محسوبة بالجرام والسعرات والماكروز (25 إفطار، 35 غداء، 25 عشاء، 15 سناكس) مع إمكانية إضافة وجبات مخصصة.
  - توليد وحفظ جدول غذائي ليوم كامل يطابق سعرات المتدرب تلقائياً، مع ميزة **استبدال أي وجبة ببديل مكافئ** ومشاركة الجدول عبر واتساب.
- **6 برامج تدريبية علمية + وضع الجيم المباشر (Live Gym Mode)**:
  - برامج معتمدة (`PPL`, `Upper/Lower`, `Arnold Split`, `Bro Split`, `Anterior/Posterior`, `Full Body`).
  - تسجيل الأوزان والعدّات في الجيم، مؤقت راحة صوتي عبر `Web Audio API` مع أزرار تحكم (`+15ث / -15ث`)، وزر **"⚡ الجهاز مشغول؟"** لاقتراح تمرين بديل فوري لنفس الزاوية العضلية.
  - حفظ وعرض **سجل التمارين المكتملة (Workout History)** وحجم التدريب الإجمالي (`Volume Kg`).
- **متتبع شرب الماء اليومي ومنحنى تطور الوزن (SVG Chart)**:
  - عداد تفاعلي لأكواب الماء اليومية (`+250 مل`).
  - رسم بياني متجهي (`SVG Trend Chart`) يوضح مسار تطور الوزن عبر الأسابيع، مع إرسال تقرير المتابعة الأسبوعي المنسق مباشرة لواتساب الكوتش.

## 🚀 طريقة التشغيل السريع (Quick Start)

### 1. التشغيل عبر خادم PowerShell المدمج (موصى به لتفعيل PWA)
افتح نافذة PowerShell داخل مجلد المشروع وشغّل الأمر:
```powershell
./server.ps1 -Port 8080
```
ثم افتح المتصفح على الرابط: `http://localhost:8080`

### 2. التشغيل المباشر
يمكنك أيضاً فتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Safari, Firefox) أو عبر إضافة **Live Server** في VS Code.

## 🔑 حسابات الدخول والخصوصية (Authentication & Isolation)

تم عزل حسابات المتدربين بالكامل بحيث يرى كل مشترك بياناته، جدوله التدريبي المخصص، نظامه الغذائي، وسجل متابعته فقط دون إظهار أي تفاصيل تخص مشتركين آخرين أو شريط تبديل عام. كما يمتلك الكوتش ميزة **"👁️ حسابه"** من لوحة التحكم لمعاينة حساب أي متدرب على حدة:

| الدور / الحالة | اسم المستخدم (`Username`) | كلمة المرور (`Password`) | الوصف |
| :--- | :---: | :---: | :--- |
| **👑 الأدمن الرئيسي (Admin)** | `El_Coach` | `123123` | حساب الإدارة الرسمي بصلاحيات كاملة لإدارة المشتركين، تعديل الخطط، الدفع، والنسخ الاحتياطي |
| **🧪 حساب كوتش تجريبي** | `coach` | `admin` | حساب تجريبي احتياطي بصلاحيات لوحة الكوتش |
| **🟢 متدرب نشط** | `ahmed` | `123` | اشتراك ساري (باقي 20 يوماً) - برنامج `PPL` وسجل قراءات وزن متعدد |
| **🟡 متدرب ينتهي قريباً** | `sara` | `123` | تنبيه قرب انتهاء الاشتراك (باقي يومان) - برنامج `Upper / Lower` |
| **🔴 متدرب منتهي** | `khaled` | `123` | اشتراك منتهي (0 يوم) - يعرض شاشة الإغلاق المؤقت وتجديد الاشتراك برفع الإيصال |
